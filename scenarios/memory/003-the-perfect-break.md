# Scenario 003 — Discovering the Value of Rest

## Purpose

Teach the Intelligence that successful vacations are not measured by activity alone.

---

## Initial State

The family attempts to maximize every park day.

Observed behavior:

* 18,000+ steps
* Late dinners
* Frequent rushing
* Missed reservations
* Increased stress

---

## New Observation

During one vacation, heavy rain leads the family back to the resort.

Unexpectedly:

* Kids swim.
* Parents relax.
* Everyone reports this became their favorite afternoon.

Post-trip reflections repeatedly mention the pool.

---

## Expected Memory Changes

Create:

* Experience Memory
* Emotional Memory
* Preference Memory

The Intelligence learns that scheduled downtime improves this family's experience.

---

## Future Recommendation

Instead of maximizing attractions, suggest:

> "It looks like this afternoon might be a great opportunity for a pool break before dinner. Your family has really enjoyed slowing down on previous trips."

---

## Things That Should NOT Happen

* Assume every family wants midday breaks.
* Recommend rest solely because of weather.
* Forget why the memory was created.
