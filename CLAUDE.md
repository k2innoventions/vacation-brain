# Claude Code Instructions — Vacation Brain

## Project Role

You are helping build Vacation Brain, an AI travel companion app. The primary product experience is mobile-first, not web-first.

## Product Promise

> Go make memories that become stories. We'll handle the rest.

Every implementation decision should support this promise.

## Product Philosophy

Vacation Brain should:
- Reduce cognitive load
- Remember what matters
- Think ahead
- Explain recommendations
- Respect attention
- Optimize for stories, not statistics

Vacation Brain should not:
- Maximize screen time
- Overwhelm users with choices
- Guess when uncertain
- Interrupt without meaningful value
- Build features just because they are clever

## Technical Direction

Preferred stack:
- Expo React Native
- TypeScript
- Supabase
- Supabase Auth
- GitHub as source of truth

## Build Standards

Before making changes:
1. Read `docs/00-publishing-brand-standards.md`
2. Read `docs/01-product-manifesto.md`
3. Read relevant architecture docs
4. Keep the app mobile-first
5. Favor simple, composable architecture

## UX Standards

The app should feel calm, thoughtful, magical but not childish, premium but approachable, and useful without being needy.

Avoid clutter. Empty space is a feature.

## Implementation Rule

Do not create unnecessary complexity. Build the smallest version that strengthens the promise.
