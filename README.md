# Vacation Brain

> Go make memories that become stories. We'll handle the rest.

Vacation Brain is an AI travel companion designed to help families spend less time managing travel logistics and more time living the moments they came for.

This repository contains the source of truth for the Vacation Brain product, documentation, architecture, prompts, and mobile app build.

## Core Promise

Vacation Brain exists so travelers can be more present.

Every recommendation, notification, screen, and system decision should support one goal:

**Return time. Reduce stress. Create stories.**

## Initial Stack

- Mobile app: Expo React Native
- Backend: Supabase
- AI builder: Claude Code
- Source of truth: GitHub
- Product brain/docs: ChatGPT Project + repository docs

## North Star

Vacation Brain is not the hero.

The traveler is.
