# Vacation Brain MVP Scope

**Version:** 0.1  
**Status:** Draft

---

# MVP Goal

Build the smallest real mobile app that proves Vacation Brain can make a traveler feel understood before and during a trip.

The MVP does not need every integration. It needs one magical, credible experience.

---

# MVP Thesis

A daily trip briefing is the best first wedge.

It is useful before complex real-time integrations exist, works well on mobile, and demonstrates the core promise:

> Go make memories that become stories. We'll handle the rest.

---

# Initial User Flow

1. User creates account
2. User creates travel profile
3. User adds family members
4. User creates a trip
5. User answers trip goals
6. Vacation Brain generates a daily briefing
7. User can ask follow-up questions

---

# MVP Features

## Required

- Authentication
- Family/traveler profile
- Trip creation
- Preference capture
- Daily briefing
- Basic chat follow-up
- Memory capture structure
- Supabase-backed data model

## Nice to Have

- Weather integration
- Wait-time integration
- Push notifications
- Location awareness
- Saved recommendations
- Shareable trip plan

## Not MVP

- Booking
- Payment
- Full itinerary optimizer
- Social features
- Full Disney account integration
- Complex multi-destination planning

---

# MVP Daily Briefing

A briefing should include today’s goal, weather consideration, pacing suggestion, one recommended priority, one caution, one magic moment, and one simple next action.
